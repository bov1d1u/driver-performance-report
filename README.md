# Driver Performance Report

A Python data analysis project that calculates logistics KPIs for each driver, including:

- Total deliveries
- Average delay
- Total distance
- Fuel efficiency (km/l)
- On-time delivery percentage
- Automated daily report generation
- Visual charts (matplotlib)

## Technologies Used
- Python
- Pandas
- Matplotlib

## How to Run
1. Install dependencies:
   pip install pandas matplotlib

2. Run the script:
   python Driver_Performance_Report.py
